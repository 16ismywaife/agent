# 数据结构与算法 · 刷题记录

> **为什么有这份文件**：技术实习岗 **46.9%** 要求数据结构与算法（与 Python 并列第一），
> 而这是你唯一**完全没碰过**的高频项。详细安排在 `ROADMAP-5months.md` 阶段 1。
>
> **力度定位**：**"熟悉常见数据结构"就够，不用刷 LeetCode 难题。**
> 目标是**面试时讲得清思路**，不是做出 Hard。
>
> **强度**：每周 3~4 道（≈5.5 小时）。**别追求一天 10 道，那撑不过两周。**
>
> **3 月面试时，这份文件就是你"会算法"的证据。** 所以要写"思路"，不只写代码。

---

## 写法（每条 4 行，别加负担）

```markdown
## 日期 · 题目名（来源 · 难度）

- **类型**：数组 / 链表 / 哈希表 / 双指针 / 二分 / 排序 ...
- **思路**：一句话说清怎么想的（★ 这行最重要，面试就考这个）
- **复杂度**：时间 O(?) / 空间 O(?)
- **卡在哪**：（没卡就写"没卡"）
```

**为什么"思路"那行最重要**：面试官不会让你默写代码，他会问"你怎么想到的"。
**你现在不写，3 月就得重新想一遍。**

## 第一阶段：把常见结构自己实现一遍（第 1~3 周）

> **不看答案，手写一遍。** 这是"会用"和"会写"的分界。
> 能默写出来，才算真的熟。

- [ ] **数组 / 列表** —— 随机访问 O(1)，插入删除 O(n)
- [ ] **链表** —— 插入删除 O(1)，访问 O(n)。**先自己定义 Node 类**
- [ ] **栈** —— 后进先出。用 `list` 的 `append`/`pop` 实现
- [ ] **队列** —— 先进先出。用 `collections.deque` 实现（**想想为什么不用 list**）
- [ ] **哈希表** —— 查找 O(1)。用 `dict`，**并能说清"为什么快"**
- [ ] **二分查找** —— O(log n)。**注意边界（左闭右开还是双闭）**

## 第二阶段：排序 + 双指针（第 4~6 周）

- [ ] **冒泡排序** O(n²) —— 能手写
- [ ] **快速排序** O(n log n) —— **能说清"分治"和"基准值"**
- [ ] **归并排序** O(n log n) —— 能说清"分 + 合"
- [ ] **双指针** —— 典型场景：有序数组找两数之和
- [ ] **滑动窗口** —— 典型场景：最长无重复子串

**★ 每学一个排序，回答自己**：为什么快排平均 O(n log n)、最坏 O(n²)？
