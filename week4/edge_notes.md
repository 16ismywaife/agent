## 四、这些数字什么意思（★ 这个方向的核心认知）

```
GFLOPs / 参数量  →  模型【有多重】   （静态，算出来的）
FPS             →  模型【跑得多快】   （动态，测出来的）
```

**为什么 FPS 是 Edge 方向的关键指标**：视频通常是 **25–30 FPS**，处理速度低于它就跟不上实时 —— 会丢帧，或者延迟越积越多。
