## 一、这个方向的关键指标（★ 要能自己讲出来）

| 指标 | 为什么关键 |
|---|---|
| **FPS** | 视频通常 **25–30 FPS**；处理速度低于它就跟不上实时（丢帧 / 延迟累积） |
| **显存占用** | 决定能不能跑更大模型 / 更高分辨率 |
| **GFLOPs / 参数量** | 模型复杂度的**静态**指标 —— **和实际 FPS 不是一回事** |

### ★★ 最核心的一个区分

```
GFLOPs / 参数量  →  模型【有多重】   （静态，算出来的）
FPS             →  模型【跑得多快】   （动态，测出来的，受硬件/精度/批大小影响）
```

**这个区分我不只是知道 —— 我的论文就是在证明它**：

> 主流计数器漏计注意力矩阵乘 → 报告的 **12.72 GFLOPs** 实际是 **19.50 G（+53%）**；
> 而"删掉最贵的 P2 注意力"在**报告口径**下只降 **2%**，在**修正口径**下降 **26%**，
> FPS **88.6 → 101.1（+14.1%）**，精度持平。

### 什么时候 FPS 不重要

| 场景 | 对 FPS 的要求 |
|---|---|
| 离线分析视频 | 无所谓，慢慢跑 |
| 实时监控 | **必须 ≥ 视频帧率** |
| 边缘设备（Jetson 之类） | 算力受限，要同时压模型大小与延迟 |
